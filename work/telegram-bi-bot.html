Project P-02 · Dublin City University coursework

Telegram BI bot

A Python Telegram bot that uses web scraping, API integration and database management to fetch and deliver real-time data to users. It runs on a schedule with cron tasks, so the information is always up to date.

Code
Code available on request
Credit
With Bohdan Boiprav
Stack
Python · BeautifulSoup · requests · PostgreSQL

01 What it is

The bot is hosted on Koyeb servers and uses a PostgreSQL database for data storage. Users can access stocks, cryptocurrencies, news and other trackers directly through the Telegram interface.

02 Method

  • Web scraping. BeautifulSoup and the requests library scrape data from multiple websites.
  • API integration. Connects to the NewsAPI.org API to retrieve the live top-5 business news in the United States.
  • Database management. Fetched data is stored in a PostgreSQL database for quick, organised access.
  • Scheduling. Cron tasks run the bot on a schedule so the data stays current.

03 Usage

  1. Open t.me/assistantba_bot.
  2. Send the /start command to begin and receive a greeting.
  3. Use the bot’s commands to get stocks, cryptocurrencies, news or other trackers.
