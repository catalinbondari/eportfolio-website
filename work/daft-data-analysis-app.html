Project P-04 · Dublin City University coursework

Daft.ie data analysis app

An application that helps users analyse and visualise property data from Daft.ie, a popular Irish property website.

Code
Repository on GitHub
Credit
Solo
Stack
Python · BeautifulSoup · Requests · Tkinter

01 What it does

  • Scrapes and cleans listings. Python libraries collect and process data from Daft.ie automatically.
  • Secure user authentication. A login and registration system protects user privacy.
  • Storage and visualisation. Stores scraped data and offers an interactive dashboard for charts and graphs based on user filters.
  • Search and filter. Search properties by location and price range.
  • Real-time parsing. Parses data directly from Daft.ie at the click of a button.
  • CSV cleaning tool. Cleans downloaded CSV files by removing unwanted values.

02 Why it helps

  • Effortless data collection: saves time compared with manual gathering.
  • Clean, organised data: a structured dataset for analysis.
  • Visual insights: trends and patterns in the property market are easy to spot.
  • Informed decisions: useful data for property investors, renters and market researchers.

Built for real estate investors, property renters, market researchers and anyone interested in Irish property data.
