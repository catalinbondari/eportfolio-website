01 Context

Weekly Market Update is a personal project: a weekly markets briefing that runs in the browser as a click-through presentation.

02 Problem

A weekly briefing has to bring together the week’s stories, the charts that support them and something to say about each, in a form that can be presented.

03 Approach

  • Public sources only. Charts are built from public sources (U.S. Treasury, FRED, wire reports).
  • A custom chart engine in plain HTML and JavaScript renders the charts.

04 What it does

  • Pick a view, then step through the week’s stories one at a time.
  • Charts for each story, built from the public sources above.
  • Presenter notes to accompany the slides.

05 Stack

  • HTML
  • JavaScript
  • Custom chart engine
  • Python (build and validate step)

06 Notes

The repository is private. Code available on request.
